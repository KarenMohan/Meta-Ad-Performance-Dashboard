# Meta-Ad-Performance-Dashboard

An interactive Power BI dashboard designed to analyze and understand Meta (Facebook and Instagram) advertising performance.

## Project Overview

This project analyzes advertising data to identify patterns and insights across different campaigns and audience segments. The dashboard tracks key metrics such as clicks, views, purchases, and engagement.

## Key Analysis

* Analyzed ad performance by **age, gender, country, ad type, and time**
* Tracked key performance indicators including **clicks, views, purchases, and engagement**
* Used **DAX** to create calculated measures and KPIs
* Built interactive Power BI charts, filters, and visualizations
* Identified patterns to understand which advertisements and audience segments performed better

## Tools Used

* Power BI
* DAX
* Data Analysis
* Data Visualization

## Objective

The goal of this project is to transform advertising data into meaningful business insights that can help understand campaign performance and audience behavior.
